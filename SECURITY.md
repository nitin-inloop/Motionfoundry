# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.4.x   | :white_check_mark: |
| < 1.4.0 | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues. Instead, open a private security advisory in the repository's **Security > Advisories** tab with a minimal reproduction. We respond within 48 hours.
