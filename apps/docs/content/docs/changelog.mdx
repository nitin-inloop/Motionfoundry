# Changelog

### v2.4.1 (2026-10-16)

- **Changed**: `EclipseGradient` defaults to a cool lavender corona (`#a8aeff` / `#caabd3`, rim `#0d3040`, speed 3, ring size 0.5, no rays).
- **Removed**: `HoldToConfirm` (it was never published to npm).
- **Changed**: landing hero is plain black; Plasma removed from the landing shader showcase.

### v2.4.0 (2026-10-16) — Cards, loaders & rotating icons

- **Added**: `RotatingIcons` (headline accent that cube-flips through icons), `CreditCard` (pointer-following glow + tilt), `AccordionCards` (horizontal panels that expand on hover/focus), `ProgressBar` (spring fill with sheen), `SkeletonShimmer` (synced shimmer placeholders), and `MoonPhaseLoader` (moon cycling through its phases).
- **Changed**: the landing hero now rotates icons instead of words.
- **Note**: 2.2.0 and 2.3.0 were staged but never published; 2.4.0 includes everything from both.

### v2.3.0 (2026-10-16) — Scroll, Shaders & UI

- **Added**: 5 dark WebGL shader backgrounds, hand-written GLSL with CSS fallbacks: `NebulaGradient`, `PlasmaGradient`, `SilkGradient`, `EmberGradient`, `EclipseGradient`.
- **Added**: 10 more Lenis-style scroll components: `ScrollCoverflow`, `SplitScreenScroll`, `PinnedSteps`, `ParallaxColumns`, `ScrollWordSwap`, `ScrollTiltCards`, `ScrollPathDraw`, `ScrollFocusList`, `SnapSections`, `ScrollColorShift`.
- **Added**: UI collection — 50 animated primitives built from scratch (no Radix/shadcn), following WAI-ARIA patterns: `Button`, `IconButton`, `ButtonGroup`, `CopyButton`, `ToggleGroup`, `LikeButton`, `SplitButton`, `FloatingInput`, `OtpInput`, `PasswordInput`, `TagInput`, `NumberStepper`, `RangeSlider`, `RadioCards`, `SegmentedControl`, `Select`, `Combobox`, `FileDropzone`, `StarRating`, `Tabs`, `Breadcrumb`, `Dialog`, `Drawer`, `AvatarGroup`, `Badge`, `Pagination`, `Stepper`, `Accordion`, `BottomSheet`, `Popover`, `HoverCard`, `Tooltip`, `ProgressRing`, `StatCard`, `BarChart`, `Sparkline`, `TreeView`, `DropdownMenu`, `DataTable`, `ActivityFeed`, `ContributionHeatmap`, `ImageCompare`, `NavigationMenu`, `ContextMenu`, `AlertDialog`, `Carousel`, `SidebarNav`, `Menubar`, `Toast`, `RotatingIcons`, `MoonPhaseLoader`, `CreditCard`, `AccordionCards`, `ProgressBar`, `SkeletonShimmer`.
- **Changed**: the Gradients collection is now **Shaders** (`--collection gradients` still works in the CLI). Site navigation lists Scroll, Shaders, then UI; Core, Studio Kit, and Text FX stay in the package and remain reachable by URL.
- **Added**: Dark / Light toggle on every component preview and design-system preview, with dark and light variants derived for any brand preset.
- **Changed**: docs sidebar groups all setup and guide pages under Docs; redesigned typography-led landing page.

### v2.2.0 (2026-10-16) — Gradients, Text FX & Scroll

- **Added**: Gradients collection (8, all props customizable): `MeshGradient`, `AuroraRibbons`, `ConicGradient`, `LiquidGradient`, `WaveGradient`, `GradientOrbs`, `GrainGradient`, `SpotlightGradient`.
- **Added**: Text FX collection (8, GSAP-style, built from scratch with no GSAP dependency): `SplitText`, `MaskWipeText`, `ElasticLetters`, `TextOnPath`, `RollingText`, `MarkerHighlight`, `ScatterText`, `CubeFlipWords`.
- **Added**: Scroll collection (8, Lenis-style smooth scrolling built from scratch with no Lenis dependency): `SmoothScroll`, `ParallaxLayers`, `ScrollFillText`, `HorizontalScroll`, `StickyStackCards`, `VelocityMarquee`, `ScrollZoomReveal`, `ScrollTimeline`.
- **Added**: "Gradient Backgrounds" and "Scroll Animations" categories; Components page filters (collection, category, engine, new in v2.2, sort) synced to the URL; live v2.2 showcases on the landing page.

### v2.1.0 (2026-10-16) — Studio Kit Collection

- **Added**: 24 Studio Kit components ported from Swirl Studio Kit onto the MotionFoundry conventions (CSS Modules, typed props, reduced-motion support, no Tailwind or icon dependencies): `BlurInText`, `Typewriter`, `NumberTicker`, `SplitReveal`, `RotatingWords`, `ShimmerText`, `ShinyBorderButton`, `ConfettiButton`, `LoadingButton`, `SlideFillButton`, `ToggleSwitch`, `AnimatedCheckbox`, `FlipCard`, `SwipeCards`, `RevealCard`, `DrawBorderCard`, `Meteors`, `BeamLines`, `GridPulse`, `OrbitLoader`, `PulseLoader`, `NotificationStack`, `ReorderList`, `ExpandableSearch`.
- **Added**: New **Loaders and Feedback** category, registry `collections`, and `npx motionfoundry list --collection <id>`.
- **Added**: Live previews with prop controls, a generated usage snippet, and Props/Accessibility tabs on every component page; `/collections/studio-kit` showcase.
- **Fixed**: `@motionfoundry/ui` now ships real compiled components (ESM + CJS), declarations, and a collision-free `styles.css` instead of placeholder exports.
- **Fixed**: The CLI bundles its registry (works outside this monorepo), runs correctly via `npx` on Windows and symlinked bins, and installs stylesheets to `components/styles/` so component imports resolve.

### v2.0.0 (2026-10-16) — Complete 24-Component Catalog Replacement

- **Replaced**: Complete public catalog replaced with 24 new components across 6 categories:
  - **Advanced Text Animations**: `KineticType`, `GlyphCascade`, `TextMorph`, `OrbitingWords`, `AuroraHeadline`
  - **Interactive Buttons and Controls**: `MagneticButton`, `VelocityButton`, `ElasticPressButton`
  - **High-End Animated Cards**: `ConstellationCard`, `LiquidGlassCard`, `HoloTiltCard`, `MorphingBorder`
  - **Reveals and Continuous Motion**: `PortalRevealPanel`, `InfiniteMarquee`, `ScrollNarrative`, `ParallaxDepthScene`
  - **Animated Backgrounds and Visual Effects**: `FluidMeshBackground`, `NoiseAurora`, `OrbitingParticles`, `LiquidBlob`
  - **Developer-Interface Animations**: `MagneticDock`, `ScrollVelocityProgress`, `MorphingCommandPalette`, `StaggeredGridReveal`
- **Removed**: All legacy v1 catalog entries removed from `packages/ui`, `registry/registry.json`, and CLI installer.
- **Added**: Full-preview canvas mode and expanded component-specific customization controls on all 24 component detail pages.
